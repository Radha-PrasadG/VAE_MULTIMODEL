DEEP GENERATIVE FRAMEWORK
VAE MODEL SUMMARY
============================================================

Project Objective
-----------------
The project uses Variational Autoencoders (VAEs) to learn compact
latent representations of different data types and generate
synthetic data. The current framework supports:

1. Image data
2. CSV / tabular data
3. Text data

The VAE follows the general pipeline:

Input Data
    ↓
Preprocessing
    ↓
Encoder
    ↓
Latent Representation (μ, log σ²)
    ↓
Reparameterization
    ↓
Decoder
    ↓
Reconstructed / Synthetic Data

The training objective combines:
    Total Loss = Reconstruction Loss + KL Divergence Loss


============================================================
1. IMAGE VAE
============================================================

Dataset
-------
MVTec AD - Bottle Category

Data Type
---------
Images

Preprocessing
-------------
- Images are loaded from the MVTec AD bottle dataset.
- Images are resized to 128 × 128 pixels.
- Pixel values are normalized to the range [0, 1].
- Images are arranged into batches for training.

Input Shape
-----------
128 × 128 × 3

Model Components
----------------
Encoder:
- Convolutional layers extract visual features.
- The encoder maps the image to a lower-dimensional latent space.
- It produces μ (mean) and log variance.

Latent Space:
- Reparameterization trick is used:
      z = μ + σ × ε
  where ε is sampled from a standard normal distribution.

Decoder:
- Transposed convolution / upsampling layers reconstruct the image.
- The decoder maps the latent vector back to image space.

Loss
----
- Reconstruction Loss measures the difference between the original
  and reconstructed image.
- KL Divergence regularizes the latent distribution.

Output
------
Synthetic bottle images generated by sampling latent vectors.

============================================================
4. COMMON VAE ARCHITECTURE
============================================================

Encoder
-------
The encoder converts the input into a latent probability
distribution represented by:

μ        = Mean of latent distribution
logvar   = Log variance of latent distribution

Reparameterization Trick
------------------------
A latent vector is sampled as:

z = μ + exp(0.5 × logvar) × ε

where:

ε ~ N(0, I)

Decoder
-------
The decoder takes the sampled latent vector and attempts to reconstruct
the original input.

Loss Function
-------------
The VAE objective is:

L = L_reconstruction + β × L_KL

Reconstruction Loss:
Measures how closely the generated output matches the input.

KL Divergence:
Encourages the learned latent distribution to remain close to a
standard normal distribution.

============================================================
8. SUMMARY
============================================================

The project demonstrates a multi-modal synthetic data generation
framework using VAEs.

The image VAE learns visual features from MVTec AD.
The tabular VAE learns the distribution of customer churn data.
The text VAE learns latent representations of SMS messages.

The common VAE architecture allows different data modalities to be
processed through specialized encoders and decoders while using the
same underlying principles of latent representation, reconstruction,
and KL-divergence regularization.
